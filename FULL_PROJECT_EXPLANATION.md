## Function and Variable Explanation (Complete Runtime Symbol Map)

### persev-compiled/backend/index.js
Functions:
- startServer(port): Starts Express on requested port. If port is busy (EADDRINUSE), recursively retries on next port.

Variables:
- express: Express module import.
- path: Node path module import.
- siteData: Imported data object containing site/events/leaderboard.
- app: Express application instance.
- PORT: Initial preferred port from env or 3000.
- frontendDir: Absolute path to served frontend folder.
- registrations: In-memory array storing posted registrations.
- event: Matching event looked up by eventId in register endpoint.
- saved: Registration object persisted in registrations.
- server: Current HTTP server instance from app.listen.
- nextPort: port + 1 used for fallback retry.

Routes and behavior:
- GET /api/health: Health check JSON.
- GET /api/site: Returns siteData.site.
- GET /api/events: Returns siteData.events.
- GET /api/leaderboard: Returns siteData.leaderboard.
- POST /api/register: Validates payload and stores registration.
- GET /api/registrations: Returns in-memory registrations.
- Static middleware: Serves frontendDir with extensions ['html'], so /events resolves to events.html.

### persev-compiled/backend/data/siteData.js
Variables:
- PLACEHOLDER_MEDIA: Shared placeholder path used by dataset entries.
- site: Top-level branding/hero metadata.
- events: Array of event records (id, name, category, description, logo, eventHeadPhoto).
- leaderboard: Event-ended flag plus school points list.

Exports:
- module.exports = { site, events, leaderboard }: Backend API payload source.

### persev-compiled/frontend/static/site-data.js
Variables:
- PLACEHOLDER_IMAGE: Placeholder image path used by simplified static renderer.
- SITE_DATA: Hardcoded client-side content object with title/theme/description/contact/events/committee/leaderboard/quickLinks.

- injectGlobalContent(): Injects title/theme/description/contact into matching data-* targets.

Variables:

- title: Element with [data-site-title].
