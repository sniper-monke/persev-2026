# Perseverantia Website (Simplified)

This is a full static rebuild optimized for readability and maintainability.

## What changed
- Removed duplicated files, minified inline scripts, and unused assets.
- Replaced all media references with a single placeholder image.
- Switched to hardcoded data in one source file.
- Kept pages small, semantic, and easy to edit.
