# Perseverantia Backend (Simplified)

This repository is a full rebuild focused on clarity.

## What changed
- Replaced database and admin complexity with hardcoded data.
- Kept only essential API endpoints.
- Removed legacy routes, scripts, and duplicated static content.
- Replaced all media references with one placeholder asset.

## Endpoints
- `GET /api/health`
- `GET /api/site`
- `GET /api/events`
- `GET /api/leaderboard`
- `POST /api/register`
- `GET /api/registrations`

## Run
1. `npm install`
2. `npm start`

Server default: `http://localhost:3000`
